# Full-resolution dynamical shock propagation

This package will compare four discrete-time disruption models on the full 4,050-node OECD ICIO network. It reuses `results_full_network/` generated by the existing structural pipeline on `analisys-branch`; it does not aggregate to 12 broad sectors.

## Network definition
- Node: economy × detailed industry.
- Directed edge i -> j: supplier i provides intermediate inputs to buyer j.
- Monetary flow Z_ij is in million current USD.
- P_ij = Z_cross_ij / total intermediate purchases of buyer j. The numerator excludes self-flows; the denominator includes self-use.
- Exposure e_j = sum_i P_ij d_i = (P.T @ d)_j.
- d_i in [0,1] is a dimensionless simulated disruption index, not observed output loss.

## Four models
1. Clipped linear: d+ = clip((1-rho)d + beta P.T d, 0, 1).
2. Bilinear SIS: d+ = clip((1-rho)d + (1-d) * beta P.T d, 0, 1).
3. MMCA edge-product SIS: d_j+ = (1-rho)d_j + (1-d_j)[1-product_i(1-q_ij)], q_ij=clip(beta P_ij d_i,0,1).
4. Exponential-hazard SIS: d+ = clip((1-rho)d + (1-d)*(1-exp(-beta P.T d)),0,1).

All have zero-state Jacobian J0=(1-rho)I+beta P.T and local threshold beta_c=rho/spectral_radius(P.T). This is a local mathematical stability diagnostic, not an observed economic crisis threshold.

For a fixed admissible state, the one-step update obeys Model 1 >= Model 2 >= Model 3 >= Model 4. This does not prove arbitrary full trajectories remain ordered after their states diverge. Model 3 uses sparse edge-wise log products with explicit q=1 handling.

## Run
From repository root, install dependencies and tests:

```bash
python -m pip install -r code/dynamical_shock_propagation/requirements.txt
python -m unittest discover -s code/dynamical_shock_propagation/tests -v
```

Full baseline census (all eligible sources, all models):

```bash
python -m code.dynamical_shock_propagation.run_all --csv data/2022_SML.csv --matrix-dir results_full_network --out results_dynamics --source-mode all
```

A fast smoke run still uses the full 4,050-node network, but restricts source nodes:

```bash
python -m code.dynamical_shock_propagation.run_all --csv data/2022_SML.csv --matrix-dir results_full_network --out results_dynamics_smoke --source-mode top-k --top-k 12 --skip-sensitivity --skip-interventions
```

Subset modes select source shocks only; they never reduce or aggregate the network. Derived matrices and result tables should generally remain local rather than be committed.

Results are counterfactual model simulations, not forecasts or measured economic losses. Gross-output-weighted disruption is an index, not monetary loss. Model steps are abstract, not calendar time. The signed-substitution model and Leontief benchmark are intentionally excluded.
